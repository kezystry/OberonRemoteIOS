# Project notice

This is an independent iOS prototype for interoperability with Oberon Remote Input. It is not an official app and is not affiliated with SamsidParty.

Protocol reference: https://github.com/SamsidParty/OberonRemote
Original setup guide: https://www.samsidparty.com/docs/software/oberon-remote/setup-guide

The iOS source in this folder was written as a new implementation from the documented packet format and observable Xbox-side protocol. No source files from the original project are bundled here. Oberon Remote Input is distributed under its own license; consult the original repository before redistributing any derivative or modified Oberon source.
